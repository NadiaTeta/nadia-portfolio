PitchBridge

PitchBridge is an inclusive venture financing platform built for Rwanda's startup ecosystem. It bridges the gap between entrepreneurs seeking capital and investors looking for vetted opportunities, with a structured verification system that builds trust on both sides of the marketplace.

Key Features

  • Bronze / Silver / Gold multi-tier entrepreneur verification with document review workflows
  • Real-time messaging between entrepreneurs and investors powered by Socket.IO
  • Admin dashboard with user management, document approval, and account status controls
  • Automated transactional email notifications for approvals, rejections, and onboarding via Resend
  • Cloudinary-powered file and video upload with configurable size limits
  • JWT-based authentication with role-based access control (Entrepreneur / Investor / Admin)
  • Privacy Policy and EULA referencing Rwanda's Law No. 058/2021 on personal data protection
  • Fully responsive, accessible UI with a custom design system in React + TypeScript

Architecture

  • Frontend: React + TypeScript, deployed on Netlify with custom domain (nukita.netlify.app)
  • Backend: Node.js + Express REST API, deployed on Render
  • Database: MongoDB with Mongoose ODM for flexible data modeling
  • File storage: Cloudinary for images, documents, and video pitch uploads
  • Email: Resend API via a verified custom domain for reliable delivery
  • Real-time: Socket.IO for persistent bidirectional messaging between users
